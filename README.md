# PsychoBotTG

Telegram-бот с веб-интерфейсом для психологической поддержки.

## Структура

- `main.py` — основной скрипт бота
- `bot/` — логика бота (Dockerfile, обработчики)
- `web/` — веб-интерфейс (Flask, SocketIO)
- `example.env` — пример переменных окружения
